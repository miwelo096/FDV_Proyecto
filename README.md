# Tutoría:
## Teclado:
- **WASD** para moverse.
- **Shift Izquierdo** para pasar a modo agachado.
- **Espacio** para pasar a modo carrera.
- **Q** para seleccionar objetos lanzables si los hay en el inventario.
- **Mouse derecho** para lanzar el objeto lanzable seleccionado.
- **E** para interacción del juego como abrir la puerta o resolver puzzles.
- **ESC** para abrir menú de pausa.

## Mecanicas:
- Si te **agachas** debajo de una mesa (rectángulo blanco grande), los enemigos no te detectan.
- Si te agachas mientras corres (modo carrera con movimiento). haces un crouch run.
- Si recoges un **objeto** (cuadrado blanco), se traslada al inventario.
- Si clicas un **objeto** del inventario lo sueltas y durante unos segundos no lo puedes coger de nuevo.  
- El **enemigo** (cuadrado negro) no te detecta a través de las paredes ni si estás debajo de la mesa.

# Tutorial del demo:
El jugador empieza en una escena en blanco y tiene que ir a otra escena donde aparecera los enemigos.
El jugador tiene que coger la llave para salir de la escena y finalizar el juego. Para ello, tiene que aplicar las tecnicas de sigilo y esconderse de los enemigos para no perder vidas, en total tiene 3 vidas💗.
Cuando consigue la llave tienes que utilizarla en la puerta para salir.
